# 메디컬 맵

대한민국의 의과대학·의학전문대학원과 전공의 수련병원을 하나의 인터랙티브 지도에서 찾아보는 웹 애플리케이션.
권역·기관 유형·병원 특성으로 걸러 보고, 지도에서 기관을 눌러 상세 정보를 확인하고, 대학과 병원 사이를 오갈 수 있다.

데이터 기준일은 **2026-10-29**이며, 값마다 출처와 기준 시점, 검증 상태를 따로 기록한다.
확인하지 못한 값은 0이나 빈칸으로 채우지 않고 **미확인**으로 표시한다.

---

## 주요 기능

- **지도** — 행정구역 경계 위에 190개 기관을 표시한다. 축소하면 시도 경계가 또렷해지고, 확대하면 시군구 경계가 드러난다. 마커 크기는 확대 배율에 정비례하지 않도록 양 끝을 눌러 두었고, 라벨은 겹치지 않는 만큼만 골라 보여 준다.
- **권역 필터** — 보건복지부 응급의료권역 29개 + 세종을 세부권역으로, 광역자치단체 16개를 대권역으로 쓰는 계층형 필터. 대권역을 켜면 소속 세부권역이 함께 켜지고, 일부만 선택되면 부분 선택으로 보인다.
- **중복 권역 처리** — 원주충주는 강원과 충북 양쪽에 속한다. 어느 쪽에서 켜도 양쪽에 켜진 것으로 보이고, 어느 쪽에서 꺼도 함께 꺼진다. 내부적으로는 권역 ID 를 하나만 둔다.
- **기관·특성 필터** — 병원 / 의과대학, 그리고 상급종합병원 · 2차병원 · 대학병원 · 권역응급의료센터를 자유롭게 조합한다.
- **검색** — 공식 명칭, 통용 명칭, 약칭, 소재지, 관련 대학·병원을 대상으로 찾는다. 공백·괄호·가운뎃점 차이는 무시하되 화면에는 언제나 공식 명칭을 쓴다.
- **상세 패널** — 개요 · 수련 · 진료조직 · 관련기관 · 출처 탭. 전공의 모집 정보는 인턴/레지던트와 전공과별 인원을 나눠 보여 준다. 예방의학과처럼 의과대학이 모집 단위인 경우에는 대학 패널에도 수련 탭이 뜬다.
- **데이터 정보** — 상단 메뉴에서 수록 범위, 전국 총계, 병원 특성 분류 기준, 권역 결정 근거, 출처 목록을 한 번에 볼 수 있다.
- **기관 간 이동** — 상세 패널에서 관련 기관을 누르면 그 기관으로 넘어가고 지도도 함께 움직인다. 관계의 종류(부속병원·교육협력병원 등)를 함께 표시한다.
- **URL 상태** — 선택 기관과 주요 필터가 URL 에 반영되어 새로고침·뒤로 가기·링크 공유가 모두 동작한다.

## 기술 스택과 선택 이유

| 선택 | 이유 |
| --- | --- |
| **TypeScript + React 19 + Vite 7** | 패널·필터·지도의 상태를 한곳에서 일관되게 다루기 위해. Vite 는 정적 산출물만 내므로 무료 정적 호스팅에 그대로 올릴 수 있다. |
| **MapLibre GL JS 5** | BSD-3-Clause 오픈소스라 토큰·사용량 제한이 없다. 행정구역 경계, 확대별 레이어 제어, 클릭 상호작용, 줌 보간 표현을 모두 지원한다. |
| **타일 서버 없음** | 배경 타일을 쓰지 않고 **GeoJSON 경계만으로** 지도를 그린다. API 키가 없으므로 공개 저장소에 노출될 비밀도 없고, 무료 사용량을 넘길 일도 없다. 데이터 중심 화면에는 사진 타일보다 깨끗하다. |
| **글리프 서버 없음** | 지도 텍스트를 MapLibre 심볼 레이어로 그리면 한글 글리프(PBF) 수 MB 를 함께 배포해야 한다. 그 대신 라벨만 지도 위 DOM 으로 그리고, 화면 좌표에서 겹침을 솎아낸다. 한글이 또렷하고 배포 용량이 늘지 않는다. |
| **Zustand** | 지도·필터·상세 패널이 같은 상태를 보되 지도를 통째로 다시 만들지 않도록, 구독 단위를 잘게 쪼갤 수 있는 작은 상태 관리자. |
| **Tailwind CSS 3** | 정보 밀도가 높은 화면에서 간격·타이포그래피·색을 한 벌의 토큰으로 묶어 두기 위해. 색상·서체는 `tailwind.config.js` 에 모아 두었다. |
| **정적 JSON** | 기관 190, 모집 기록 588 규모에서는 전부 내려받아 메모리에서 거르는 쪽이 빠르고 단순하다. 데이터베이스는 넣지 않았다. 규모가 수만 건으로 커지면 그때 도입하면 된다. |
| **Python 빌드 스크립트** | 원자료가 xlsx·PDF·parquet 라서, 그 포맷을 잘 다루는 쪽을 데이터 파이프라인으로 삼았다. 앱 런타임에는 Python 이 필요 없다. |

## 설치와 실행

### 요구 사항

- Node.js 20 이상 (개발은 22.18 에서 했다)
- Python 3.11 이상 — 데이터를 다시 만들 때만 필요하다
- 브라우저 테스트용 Chrome (Playwright 가 설치된 Chrome 을 쓴다)

### 개발 서버

```bash
npm install
npm run dev          # http://localhost:5173
```

`public/data/` 와 `public/geo/` 는 저장소에 포함되어 있으므로, 받아서 바로 띄울 수 있다.

### 빌드

```bash
npm run build        # 타입 검사 후 dist/ 생성
npm run preview      # 빌드 결과 미리보기
```

GitHub Pages 처럼 하위 경로에 올릴 때는 base 를 지정한다.

```bash
MEDMAP_BASE=/medmap/ npm run build
```

### 테스트

```bash
npm run typecheck    # tsc --noEmit
npm test             # 단위 테스트 (vitest) — 권역·필터·통계·검색·모집 집계
npm run validate     # 데이터 검증 (참조 무결성·필수 필드·좌표 범위·출처)
npm run e2e          # 브라우저 테스트 (Playwright, 데스크톱/모바일)
```

### 데이터 다시 만들기

```bash
npm run build:geo    # 행정구역 경계 GeoJSON 내려받아 변환 → public/geo/
npm run build:data   # 원자료 추출 + 조립 → public/data/
npm run validate
```

`build:data` 는 아래 로컬 원자료를 읽는다. 경로는 환경변수로 바꿀 수 있다.

| 환경변수 | 기본값 | 내용 |
| --- | --- | --- |
| `MEDMAP_XLSX` | `%USERPROFILE%\Documents\고려대 의대\메디컬 목록_260922.xlsx` | 의과대학·관련 병원 목록 |
| `MEDMAP_INTERN_PDF` | 같은 폴더의 붙임1 PDF | 2026년도 하반기 인턴 모집인원 |
| `MEDMAP_RESID_PDF` | 같은 폴더의 붙임2 PDF | 2026년도 하반기 레지던트 모집인원 |
| `MEDMAP_LOGO_DIRS` | `%USERPROFILE%\Pictures\로고\ai\정리` 와 `...\Pictures\로고` | 로고 원본 폴더 (`;` 로 여러 개) |

절대 경로는 코드에 넣지 않았다. 원자료가 없으면 스크립트가 어떤 파일이 없는지 알려 주고 멈춘다.
이미 만들어진 `public/data/` 가 저장소에 있으므로, 원자료가 없어도 앱은 돈다.

### 모델에서 구별하는 것들

- **기관**과 **모집 단위**는 다르다. 가톨릭중앙의료원·고려대의료원은 통합수련 단위 하나에 병원 여러 곳이 묶인다. 예방의학과는 병원이 아니라 의과대학이 모집 단위다. 그래서 `trainingUnits` 를 기관과 별도 엔티티로 둔다.
- **관계는 다대다**다. 한 대학에 병원 여럿, 한 병원에 대학 여럿이 붙을 수 있고, 관계마다 종류(부속병원·교육협력병원·위탁운영병원)를 적는다.
- **미확인 · 해당 없음 · 실제 0** 을 구별한다. 전공의 모집인원 0명은 확인된 값이고, 자료를 못 찾은 병원은 기록 자체가 없으며 화면에 "자료 미확인"으로 나온다.
- **좌표 정밀도**를 적는다. `exact`(기관 위치) / `approximate`(부지 내 근사) / `시군구 대표점`(캠퍼스 좌표 미확인) 셋이 섞여 있다.
- **세 가지 권역**을 섞지 않는다. ① 기관이 있는 지리적 권역 ② 권역응급의료센터의 공식 관할 응급의료권역 ③ 상급종합병원 지정 제도의 진료권역. 셋을 각각 저장한다.

## 권역 정의와 그 근거

### 대권역 16개 — 현행 광역자치단체

서울 · 부산 · 대구 · 인천 · 대전 · 울산 · 세종 · 경기 · 강원 · 충북 · 충남 · 전북 · 전남광주 · 경북 · 경남 · 제주

프로젝트 지시의 대권역 목록은 16개였고 세종이 빠져 있었다. 확인 결과 **2026-07-01 광주광역시와 전라남도가 전남광주통합특별시로 통합**되어, 현행 광역자치단체는 17개가 아니라 16개다. 사용자 확인을 거쳐 **현행 행정구역 16개를 그대로 대권역으로 쓰기로** 했다. 그 결과 광주·전남은 대권역에서 하나로 합쳐지고, 빠져 있던 세종이 들어온다.

### 세부권역 30개 — 보건복지부 응급의료권역 29개 + 세종

지시서의 28개 권역 목록은 **보건복지부가 쓰는 응급의료권역**과 이름·순서가 정확히 일치했다. 「2026~2029년 권역응급의료센터 선정 기관」과 「권역응급의료센터 현황」(2023-05-01) 두 공식 자료 모두 응급의료권역을 **29개**로 열거하며, 지시서 목록에는 그중 **강원춘천**이 빠져 있었다.

- **강원춘천을 더했다(29번째).** 이 권역이 없으면 춘천의 강원대학교병원·한림대학교춘천성심병원이 어느 세부권역에도 속하지 못한다. 두 곳 모두 공식 자료에서 강원춘천 권역의 권역응급의료센터로 지정되어 있다.
- **세종을 더했다(30번째).** 응급의료권역 29개에도, 지시서 28개에도 세종은 없다. 세종이 어느 응급의료권역에 귀속되는지는 공식 자료에서 확인하지 못했다. 대권역을 현행 16개로 확정한 이상 세종이 어느 세부권역에도 속하지 않는 공백이 생기므로, 세종충남대학교병원 등이 필터·통계에서 누락되지 않도록 별도 권역으로 두었다.
- 두 항목 모두 `data/regions.json` 에 `addedBeyondPrompt: true` 와 추가 사유가 함께 기록되어 있다.

### 권역별 시군구 구성

권역에 어느 시군구가 들어가는지는 공식 고시 원문을 확보하지 못했다. 그래서 **시군구 목록은 이 프로젝트가 정의한 값**이고, `data/regions.json` 의 `sgg` 배열에 코드로 명시해 두었다. 이름만 보고 지역을 추측하지 않으며, 바꾸려면 그 JSON 만 고치면 된다.

- 2026-10-01 기준 **256개 시군구 전부**가 정확히 하나의 세부권역에 속한다(단위 테스트로 검증).
- **원주충주**만 두 대권역(강원·충북)에 걸친다. 강원 원주·횡성·영월 + 충북 충주·제천·단양.
- 2026-07-01 개편(인천 제물포구·영종구·서해구·검단구, 화성시 4개 일반구)이 반영되어 있다.

### 병원 특성 분류 기준

| 분류 | 성격 | 근거 |
| --- | --- | --- |
| 3차병원 (상급종합병원) | **공식 종별** | 보건복지부 제5기 지정 47개소 (2024-01-01~2026-12-31) |
| 권역응급의료센터 | **공식 지정** | 보건복지부 지정. 2023-05-01 44개소 / 2026-11-01 53개소 두 시기를 모두 저장 |
| 대학병원 | **관계 기반** | 의과대학과 부속·교육협력 관계가 자료로 확인된 병원. 이름이 비슷하거나 같은 법인이라는 이유만으로는 넣지 않았다 |
| 2차병원 | **서비스 자체 분류** | 상급종합병원으로 지정되지 않은 전공의 수련병원. 의료법상 종별 구분이 아니다. 종합병원·병원 종별은 확인하지 않았다 |

"3차병원"과 "상급종합병원"은 이 사이트에서 같은 뜻으로 쓰되, 그 사실을 필터 화면에 적어 두었다.
이 정의들은 `src/lib/domain.ts` 의 `TRAIT_DEFINITION` 에 있고 그대로 화면에 노출된다.

### 자동 수집에 관하여

- 행정구역 경계는 CC BY 4.0 공개 저장소에서 내려받았다.
- 좌표는 OpenStreetMap Overpass API 로 한 번 받아 캐시하고, 부족한 기관만 Nominatim 으로 조회했다. Nominatim 이용 정책에 따라 식별 가능한 User-Agent 로 초당 1건 이하로 호출했다.
- 접근 제한을 우회한 수집은 하지 않았다. 로그인이 필요하거나 robots.txt 로 막힌 경로는 쓰지 않았고, 보건복지부 자료는 보도자료 페이지에 공개된 첨부 파일을 그대로 내려받았다.
- 2023년 모집 자료처럼 공식 원문을 못 구한 항목은 언론 보도를 2차 자료로 쓰되, 출처와 `일부확인` 상태를 함께 적고 화면에도 경고를 띄운다.
- 자동 매칭 결과는 그대로 믿지 않고, 좌표가 해당 기관의 소재 시군구 경계 안에 들어오는지 점-다각형 검사로 확인했다. 틀린 매칭과 비어 있던 항목은 `data/curation/coordinates.json` 에 사람이 확정해 두었다.

### 로고를 저장소에 넣지 않은 이유

병원·대학 로고는 각 기관의 상표다. 재배포 허락을 확인하지 못했으므로 `public/logos/` 를 `.gitignore` 에 넣었고, **저장소와 배포본에는 로고 이미지가 들어가지 않는다.** 로고가 없는 기관은 화면에서 기관명 머리글자를 쓴 공통 기본 표식으로 그려진다.

로컬에서 로고를 보려면:

```bash
python scripts/build_logos.py          # 매핑 manifest 만 미리 만든다
python scripts/build_logos.py --copy   # public/logos/ 로 사본을 복사한다
npm run build:data                     # 실제로 복사된 로고만 데이터에 연결한다
```

원본 폴더는 읽기만 하며 덮어쓰지 않는다. 파일명과 기관명이 어긋나면 `data/curation/logo-manifest.json` 의 `sourceFile` 을 고치고 `manual: true` 로 두면 자동 매칭이 그 항목을 건드리지 않는다. 현재 **190개 기관 중 108개**가 매칭된다 (병원 71, 의과대학 37).

## 미구현 기능과 데이터 한계

솔직하게 적는다. 아래는 **구조는 만들어 두었으나 데이터가 없거나 아직 구현하지 않은** 항목이다.

### 데이터가 없는 항목 (화면에 "미확인"으로 표시됨)

1. **2023년 수련 모집 정보 — 일부만 수록** — 보건복지부 공고 원문의 병원별 표를 공개 웹에서 확보하지 못했다. 수록한 범위는 다음과 같고, 2026년 값으로 대신 채우지 않았다.
   - 전국 총계: 2023년 정원 인턴 3,258명 · 레지던트 1년차 3,465명, 2023년 하반기 모집 인턴 114명(44개 병원) · 레지던트 614명(196개 병원) — 모두 **언론 보도 인용**이라 `일부확인`.
   - 병원별: **하반기 44개 인턴 모집 병원 중 10개, 196개 레지던트 모집 병원 중 8개**만 확인됐다. 이 목록은 전체 명단이 아니며, 화면에도 그 경고가 함께 뜬다.
   - 상반기: 서울대학교병원 공식 공고로 확인된 3개 기관(본원 86 · 분당 36 · 보라매 22)만 `확인됨`.
   - 스키마는 `year`/`term` 을 키로 쓰므로 공고 원문을 구하면 그대로 추가된다.
2. **공식 주소** — 모든 기관이 미확인이다. 좌표는 확보했지만 도로명주소를 신뢰할 수 있는 출처에서 받지 못했다.
3. **병원 연혁** — 전부 미확인.
4. **운영 센터 · 세부 전문과 · 근무 인원** — 전부 미확인. 병원 공식 홈페이지의 진료 조직을 아직 수집하지 않았다. 홈페이지에 조직이 있다는 사실만으로 인원을 추정하지 않는다. 「진료조직」 탭에는 **모집 공고로 확인된 전공과목**만 나열하며, 이는 레지던트를 모집한 과일 뿐 병원이 운영하는 진료과 전체가 아니라는 점을 화면에 적어 두었다.
5. **병원 공식 홈페이지 링크** — 전부 미확인 (의과대학은 확보).
6. **지원자 수 · 합격자 수 · 실제 임용 인원** — 전부 미확인. 모집 정원과 혼용하지 않는다.
7. **좌표 11개 기관 미확인** — BHS한서병원, 경희대학교병원, 누네안과병원, 부산삼육병원, 서울부민병원, 안양샘병원, 인천세종병원, 좋은문화병원, 청주한국병원, 순천향대학교천안병원, 해운대부민병원. OSM·Nominatim 어디에도 등재되어 있지 않다. 지도에는 나오지 않고 목록·검색·통계에는 나온다.
8. **의과대학 캠퍼스 좌표 29개** — Nominatim 으로 11개만 확인했다. 나머지는 소재 시군구 대표점을 쓰며, 상세 패널에 "시군구 대표점"이라고 적는다.
9. **병상 수 구분** — 허가병상·운영병상·가동병상을 구별하지 못했다. 원자료에 그 구분이 없다.

### 아직 구현하지 않은 기능

- **센터·전문과 엔티티** — 타입과 빈 컬렉션만 있고 실제 레코드가 없다. 자료를 넣으면 「진료조직」 탭이 바로 채워진다.
- **2023년 전국 병원별 표** — 아래 "데이터가 없는 항목" 1번 참고.
- **공식 주소 자동 수집** — 좌표만 확보했고 도로명주소 파이프라인은 만들지 않았다.

### 구현한 지도 동작 (참고)

- **권역응급의료센터 관할 권역 하이라이트** — 권역응급의료센터를 선택하면 그 센터가 맡은 **공식 관할 응급의료권역**을 붉은 점선으로 칠한다. 필터로 고른 탐색용 권역(초록)과 색을 달리해 섞이지 않게 했다. 기관이 있는 지리적 권역·공식 관할 권역·탐색용 권역 셋을 각각 다른 값으로 저장한다.
- **같은 좌표에 모인 기관** — 캠퍼스 좌표를 확인하지 못해 같은 시군구 대표점을 쓰는 의과대학 3쌍이 한 점에 겹친다. 지도에서는 작은 원 위로 흩어 놓아 각각 누를 수 있게 했다. **표시 전용 보정**이며 데이터의 좌표와 상세 패널에 보이는 값은 그대로다.

### 원자료에서 발견한 오류

메디컬 목록 엑셀의 「관련 병원」 열에서 세 대학의 본원이 빠지고 분원이 두 번 적혀 있었다 (경북대 → 칠곡경북대 2회, 경희대 → 강동경희대 2회, 부산대 → 양산부산대 2회). 원본은 고치지 않고, `data/curation/relation-corrections.json` 에 보완 관계를 근거와 함께 추가했다. 상태는 `일부확인`이다.

보건복지부 「권역응급의료센터 현황」(2023) 붙임 원문에 "한람대학교성심병원"이라는 오기가 있어 "한림대학교성심병원"으로 바로잡아 옮겼고, 그 사실을 `data/designations.json` 에 적었다.

## 배포

GitHub Pages 를 전제로 준비했다. 별도 서버가 필요 없다 — 지도 타일 서버도, API 키도, 백엔드도 쓰지 않는다.

`.github/workflows/deploy.yml` 이 들어 있다. 저장소 설정에서 **Settings → Pages → Source: GitHub Actions** 를 켜면 `main` 에 푸시할 때마다 빌드·배포된다.

수동 배포:

```bash
MEDMAP_BASE=/<저장소이름>/ npm run build
# dist/ 를 정적 호스팅에 올린다
```

### 공개 전 점검

- [x] API 키·토큰 없음 (외부 유료 서비스를 쓰지 않는다)
- [x] 개인 PC 절대 경로가 코드에 없음 (환경변수로 받고 기본값만 스크립트 안에 둔다)
- [x] 사용자 계정 정보 없음
- [x] 대용량·임시 파일 제외 (`.cache/`, `dist/`, `node_modules/`, `test-results/`)
- [x] 경계·좌표 데이터의 라이선스와 출처 표시
- [ ] **기관 로고 사용 권한 — 미확인.** 그래서 저장소에 넣지 않았다. 공개 배포에 포함하려면 각 기관의 허락을 확인해야 한다.
- [ ] 원자료 PDF·엑셀은 저장소에 넣지 않았다. 재배포 조건을 확인하지 않았기 때문이다.
