# 메디컬 맵

대한민국의 의과대학·의학전문대학원과 전공의 수련병원, **치과대학과 부속 치과병원**, 그리고 **일본의 의학부·歯学部와
대학병원·特定機能病院·歯科 부속 병원**을 하나의 인터랙티브 지도에서 찾아보는 웹 애플리케이션.
나라·분야(의과/치과)·권역·기관 유형·병원 특성으로 걸러 보고, 지도에서 기관을 눌러
상세 정보를 확인하고, 대학과 병원, 같은 계열 병원 사이를 오갈 수 있다.

데이터 기준일은 **2026-10-29**이며, 값마다 출처와 기준 시점, 검증 상태를 따로 기록한다.
확인하지 못한 값은 0이나 빈칸으로 채우지 않고 **미확인**으로 표시한다.

수록 범위: **의과대학·의학전문대학원 40 · 병원 236**(2023~2026년 전공의 수련병원 중 지금 운영하는 곳 전체 + 상급종합병원 47 + 권역응급의료센터 53 + 의과대학 관련 병원),
**전공의 정원·모집 기록 9,179건**(2023·2024·2025·2026년 정원 전량 + 2026년 하반기 모집인원 전량),
**진료과목·과목별 전문의 수** 231개 병원(5,057개 과목 레코드, 전문의 29,147명).

치과(필터의 **분야**에서 고른다): 한국 **치과대학·치의학(전문)대학원 11 · 부속 치과병원 17**, 일본 **歯学部 29 · 歯科 부속 병원 17**.

일본(필터의 **나라**에서 켠다): **의학부 82**(防衛医科大学校 포함) · **병원 161**(대학병원 본원 82 · 분원 70, 대학과 무관한

## 주요 기능

- **나라 선택** — 한국만, 일본만, 둘 다를 필터 맨 위에서 고른다. 기본은 한국이며, 일본을 처음 켤 때 일본 데이터(약 840 KB)와 경계를 받는다. 나라를 바꾸면 지도가 그 나라에 맞춰 움직인다.
- **분야 선택** — 의과·치과를 따로 켜고 끈다. 기본은 둘 다. 치과 기관은 같은 모양(병원 원·대학 사각)에 푸른 계열로 칠하고 가운데 흰 점을 찍어 색 없이도 구별된다. 일본의 医歯 통합 대학병원(北海道大学病院 등)은 두 분야에 모두 든다.
- **같은 대학의 의과·치과대학** — 의과대학과 치과대학이 함께 있는 대학(한국 11곳, 일본 14곳)은 하나의 대학으로 보인다. 상세 패널 머리에 단과대학 탭(의과대학 / 치과대학, 日本大学은 医学部 / 歯学部 / 松戸歯学部)이 있고, 탭을 고르면 그 단과대학 위치가 지도 가운데로 온다. 두 단과대학이 1.5 km 안(같은 캠퍼스)이면 지도에는 마커 하나에 대학 이름만(예: 경희대학교), 더 멀면(강원대 춘천·강릉, 전남대 학동·용봉, 岩手医科大学, 日本大学) 단과대학마다 따로 표시하고 이름에 단과대학을 붙인다(예: 전남대학교 치의학전문대학원). '관련기관' 탭에는 두 단과대학과 그 대학병원·치과병원을 모두 보여 주고, 치과병원·대학병원에서도 같은 대학의 다른 단과대학과 병원으로 넘어갈 수 있다. 묶음 규칙은 `src/lib/domain.ts` 의 `universityGroups()`.
- **지도** — 행정구역 경계 위에 한국 304개, 일본 289개 기관을 표시한다. 오른쪽 아래 **나침반 버튼**은 지도를 돌리거나(오른쪽 끌기·두 손가락 회전) 기울인 뒤 누르면 북쪽이 위로 오게 되돌린다. 축소하면 시도 경계가 또렷해지고, 확대하면 시군구 경계가 드러난다. 마커 크기는 확대 배율에 정비례하지 않도록 양 끝을 눌러 두었고, 라벨은 겹치지 않는 만큼만 골라 보여 준다.
- **권역 필터** — 보건복지부 응급의료권역 29개 + 세종을 세부권역으로, 광역자치단체 16개를 대권역으로 쓰는 계층형 필터. 대권역을 켜면 소속 세부권역이 함께 켜지고, 일부만 선택되면 부분 선택으로 보인다.
- **중복 권역 처리** — 원주충주는 강원과 충북 양쪽에 속한다. 어느 쪽에서 켜도 양쪽에 켜진 것으로 보이고, 어느 쪽에서 꺼도 함께 꺼진다. 내부적으로는 권역 ID 를 하나만 둔다.
- **기관·특성 필터** — 병원 / 대학(의과·치과), 그리고 나라별 병원 분류(한국: 상급종합병원 · 2차병원 · 대학병원 · 권역응급의료센터, 일본: 特定機能病院 · 大学病院 本院 · 分院)를 조합한다. 선택지마다 '고르면 몇 곳이 남는지'를 숫자로 보여 주고, 분류는 나라별로 따로 걸린다(한국 분류만 고르면 일본 기관은 그대로 남는다). 지역은 큰 지역을 접고 펼칠 수 있고 이름으로 찾을 수 있다.
- **병원 계열** — 같은 대학 부속·교육병원(예: 가톨릭대 서울성모·여의도성모 등 8곳, 삼성·아산·차병원), 같은 법인(명지·영훈·은성·인당·효산의료재단, 아산재단), 공공 병원망(서울시립·경기도의료원·보훈·근로복지공단·적십자)을 잇는다. 한국 36개(병원 102곳), 일본 38개(대학별 본원·분원, 国立がん研究センター). 상세 패널 '관련기관' 탭에서 서로 오간다. 근거는 `data/curation/hospital-networks.json` 에 규칙과 함께 적는다.
- **검색** — 공식 명칭, 통용 명칭, 약칭, 소재지, 관련 대학·병원을 대상으로 찾는다. 공백·괄호·가운뎃점 차이는 무시하되 화면에는 언제나 공식 명칭을 쓴다.
- **상세 패널** — 개요 · 수련 · 진료조직 · 관련기관 · 출처 탭.
  - **수련**: 맨 위에 2023~2026년 **연도별 추이 표**를 두고, 아래에 각 시점의 전공과별 정원과 정원 내역(기본·미충원·정책적·감원)을 펼친다. '정원'(한 해 배정)과 '모집인원'(한 차례 모집)이 다른 지표라는 점을 화면에 적는다. 예방의학과처럼 의과대학이 모집 단위인 경우에는 대학 패널에도 수련 탭이 뜬다.
  - **진료조직**: 심평원에 신고된 **진료과목 전체와 과목별 전문의 수**, 총 의사 수·전문의 수·재직 전공의 수를 싣고, 전공의를 모집한 과목인지 표시한다.
- **데이터 정보** — 상단 메뉴에서 수록 범위, 전국 총계, 병원 특성 분류 기준, 권역 결정 근거, 출처 목록을 한 번에 볼 수 있다.
- **기관 간 이동** — 상세 패널에서 관련 기관을 누르면 그 기관으로 넘어가고 지도도 함께 움직인다. 관계의 종류(부속병원·교육협력병원 등)를 함께 표시한다.
- **URL 상태** — 선택 기관과 주요 필터가 URL 에 반영되어 새로고침·뒤로 가기·링크 공유가 모두 동작한다. 검색어는 글자마다 바뀌므로 히스토리를 쌓지 않고 현재 항목만 바꾼다(기관 선택과 필터만 뒤로 가기 대상).

## 기술 스택과 선택 이유

| 선택 | 이유 |
| --- | --- |
| **TypeScript + React 19 + Vite 7** | 패널·필터·지도의 상태를 한곳에서 일관되게 다루기 위해. Vite 는 정적 산출물만 내므로 무료 정적 호스팅에 그대로 올릴 수 있다. |
| **MapLibre GL JS 5** | BSD-3-Clause 오픈소스라 토큰·사용량 제한이 없다. 행정구역 경계, 확대별 레이어 제어, 클릭 상호작용, 줌 보간 표현을 모두 지원한다. |
| **타일 서버 없음** | 배경 타일을 쓰지 않고 **GeoJSON 경계만으로** 지도를 그린다. API 키가 없으므로 공개 저장소에 노출될 비밀도 없고, 무료 사용량을 넘길 일도 없다. 데이터 중심 화면에는 사진 타일보다 깨끗하다. |
| **글리프 서버 없음** | 지도 텍스트를 MapLibre 심볼 레이어로 그리면 한글 글리프(PBF) 수 MB 를 함께 배포해야 한다. 그 대신 라벨만 지도 위 DOM 으로 그리고, 화면 좌표에서 겹침을 솎아낸다. 한글이 또렷하고 배포 용량이 늘지 않는다. |
| **Zustand** | 지도·필터·상세 패널이 같은 상태를 보되 지도를 통째로 다시 만들지 않도록, 구독 단위를 잘게 쪼갤 수 있는 작은 상태 관리자. |
| **Tailwind CSS 3** | 정보 밀도가 높은 화면에서 간격·타이포그래피·색을 한 벌의 토큰으로 묶어 두기 위해. 색상·서체는 `tailwind.config.js` 에 모아 두었다. |
| **정적 JSON** | 기관 277 규모에서는 전부 내려받아 메모리에서 거르는 쪽이 빠르고 단순하다. 다만 모집 기록 9,179건(약 2.2 MB)은 첫 화면에 필요 없어서, 기관별 색인(23 KB)만 먼저 받고 상세 패널을 처음 열 때 본문을 받는다. 데이터베이스는 넣지 않았다. |
| **Python 빌드 스크립트** | 원자료가 xlsx·PDF·parquet 라서, 그 포맷을 잘 다루는 쪽을 데이터 파이프라인으로 삼았다. 앱 런타임에는 Python 이 필요 없다. |

## 설치와 실행

### 요구 사항

- Node.js 20 이상 (개발은 22.18 에서 했다)
- Python 3.11 이상 — 데이터를 다시 만들 때만 필요하다
- 브라우저 테스트용 Chrome (Playwright 가 설치된 Chrome 을 쓴다)

### 개발 서버

```bash
npm install
npm run dev          # http://localhost:5173
```

`public/data/` 와 `public/geo/` 는 저장소에 포함되어 있으므로, 받아서 바로 띄울 수 있다.

### 빌드

```bash
npm run build        # 타입 검사 후 dist/ 생성
npm run preview      # 빌드 결과 미리보기
```

GitHub Pages 처럼 하위 경로에 올릴 때는 base 를 지정한다. 저장소는 https://github.com/SeokhyeonLeeMed/med-map 이고, `main` 에 push 하면 `.github/workflows/deploy.yml` 이 저장소 이름으로 base 를 잡아 Pages 에 배포한다(저장소 Settings → Pages 의 Source 가 **GitHub Actions** 여야 한다).

```bash
MEDMAP_BASE=/med-map/ npm run build
```

Windows 의 Git Bash 에서는 앞의 `/` 를 Windows 경로로 바꿔 버리므로 `MSYS_NO_PATHCONV=1` 을 함께 준다.

```bash
MSYS_NO_PATHCONV=1 MEDMAP_BASE=/med-map/ npm run build
```

### 테스트

```bash
npm run typecheck    # tsc --noEmit
npm test             # 단위 테스트 (vitest) — 권역·필터·통계·검색·모집 집계
npm run validate     # 데이터 검증 (참조 무결성·필수 필드·좌표 범위·출처)
npm run e2e          # 브라우저 테스트 (Playwright, 데스크톱/모바일)
```

### 데이터 다시 만들기

```bash
npm run fetch:sources    # 심평원 ZIP + 2023~2026년 정원 PDF 내려받기 → .cache/
npm run build:geo        # 행정구역 경계 GeoJSON 내려받아 변환 → public/geo/
npm run build:hira       # 심평원 병원 색인 + 기관명 매칭 → .cache/hira/
npm run build:data       # 원자료 추출 + 조립 → public/data/
npm run build:logos      # 로고 사본 복사(여백 자르기) → public/logos/
npm run validate
```

`fetch:sources` 는 두 자료를 Playwright 로 받아 `.cache/` 에 둔다. 둘 다 로그인 없이 받을 수 있지만
평범한 GET 으로는 막혀서 브라우저 세션이 필요하다. 심평원 ZIP 은 `.cache/hira/extracted/` 에 풀어야 하고
(`MEDMAP_HIRA_DIR` 로 경로 변경 가능), 2023~2026년 정원 PDF 는 `.cache/quota/` 에 놓인다(`MEDMAP_QUOTA_DIR`).

`build:data` 는 아래 로컬 원자료를 읽는다. 경로는 환경변수로 바꿀 수 있다.

| 환경변수 | 기본값 | 내용 |
| --- | --- | --- |
| `MEDMAP_XLSX` | `%USERPROFILE%\Documents\고려대 의대\메디컬 목록_260922.xlsx` | 의과대학·관련 병원 목록 |
| `MEDMAP_INTERN_PDF` | 같은 폴더의 붙임1 PDF | 2026년도 하반기 인턴 모집인원 |
| `MEDMAP_RESID_PDF` | 같은 폴더의 붙임2 PDF | 2026년도 하반기 레지던트 모집인원 |
| `MEDMAP_LOGO_DIRS` | `%USERPROFILE%\Pictures\로고\ai\정리` 와 `...\Pictures\로고` | 로고 원본 폴더 (`;` 로 여러 개) |
| `MEDMAP_ADM_VER` | `20261001` | 행정구역 경계 스냅샷 |
| `MEDMAP_HIRA_DIR` | `.cache/hira/extracted` | 심평원 「전국 병의원 및 약국 현황」 CSV 폴더 |
| `MEDMAP_QUOTA_DIR` | `.cache/quota` | 연도별 전공의 정원 PDF 폴더 (`intern2023.pdf` … `resident2026.pdf`) |

절대 경로는 코드에 넣지 않았다. 원자료가 없으면 스크립트가 어떤 파일이 없는지 알려 주고 멈춘다.
이미 만들어진 `public/data/` 가 저장소에 있으므로, 원자료가 없어도 앱은 돈다.

### 모델에서 구별하는 것들

- **기관**과 **모집 단위**는 다르다. 가톨릭중앙의료원·고려대의료원은 통합수련 단위 하나에 병원 여러 곳이 묶인다. 예방의학과는 병원이 아니라 의과대학이 모집 단위다. 그래서 `trainingUnits` 를 기관과 별도 엔티티로 둔다.
- **관계는 다대다**다. 한 대학에 병원 여럿, 한 병원에 대학 여럿이 붙을 수 있고, 관계마다 종류(부속병원·교육협력병원·위탁운영병원)를 적는다.
- **미확인 · 해당 없음 · 실제 0** 을 구별한다. 전공의 모집인원 0명은 확인된 값이고, 자료를 못 찾은 병원은 기록 자체가 없으며 화면에 "자료 미확인"으로 나온다.
- **좌표 정밀도**를 적는다. `exact`(기관 건물) / `approximate`(캠퍼스·부속병원 부지의 근사 지점) 둘이 섞여 있고, 근사 좌표에는 무엇을 찍었는지 note 로 적는다. 좌표를 못 찾았을 때만 쓰는 `시군구 대표점`은 지금은 쓰이지 않는다.
- **세 가지 권역**을 섞지 않는다. ① 기관이 있는 지리적 권역 ② 권역응급의료센터의 공식 관할 응급의료권역 ③ 상급종합병원 지정 제도의 진료권역. 셋을 각각 저장한다.

## 권역 정의와 그 근거

### 대권역 16개 — 현행 광역자치단체

서울 · 부산 · 대구 · 인천 · 대전 · 울산 · 세종 · 경기 · 강원 · 충북 · 충남 · 전북 · 전남광주 · 경북 · 경남 · 제주

프로젝트 지시의 대권역 목록은 16개였고 세종이 빠져 있었다. 확인 결과 **2026-07-01 광주광역시와 전라남도가 전남광주통합특별시로 통합**되어, 현행 광역자치단체는 17개가 아니라 16개다. 사용자 확인을 거쳐 **현행 행정구역 16개를 그대로 대권역으로 쓰기로** 했다. 그 결과 광주·전남은 대권역에서 하나로 합쳐지고, 빠져 있던 세종이 들어온다.

### 세부권역 30개 — 보건복지부 응급의료권역 29개 + 세종

지시서의 28개 권역 목록은 **보건복지부가 쓰는 응급의료권역**과 이름·순서가 정확히 일치했다. 「2026~2029년 권역응급의료센터 선정 기관」과 「권역응급의료센터 현황」(2023-05-01) 두 공식 자료 모두 응급의료권역을 **29개**로 열거하며, 지시서 목록에는 그중 **강원춘천**이 빠져 있었다.

- **강원춘천을 더했다(29번째).** 이 권역이 없으면 춘천의 강원대학교병원·한림대학교춘천성심병원이 어느 세부권역에도 속하지 못한다. 두 곳 모두 공식 자료에서 강원춘천 권역의 권역응급의료센터로 지정되어 있다.
- **세종을 더했다(30번째).** 응급의료권역 29개에도, 지시서 28개에도 세종은 없다. 세종이 어느 응급의료권역에 귀속되는지는 공식 자료에서 확인하지 못했다. 대권역을 현행 16개로 확정한 이상 세종이 어느 세부권역에도 속하지 않는 공백이 생기므로, 세종충남대학교병원 등이 필터·통계에서 누락되지 않도록 별도 권역으로 두었다.
- 두 항목 모두 `data/regions.json` 에 `addedBeyondPrompt: true` 와 추가 사유가 함께 기록되어 있다.

### 권역별 시군구 구성

권역에 어느 시군구가 들어가는지는 공식 고시 원문을 확보하지 못했다. 그래서 **시군구 목록은 이 프로젝트가 정의한 값**이고, `data/regions.json` 의 `sgg` 배열에 코드로 명시해 두었다. 이름만 보고 지역을 추측하지 않으며, 바꾸려면 그 JSON 만 고치면 된다.

- 2026-10-01 기준 **256개 시군구 전부**가 정확히 하나의 세부권역에 속한다(단위 테스트로 검증).
- **원주충주**만 두 대권역(강원·충북)에 걸친다. 강원 원주·횡성·영월 + 충북 충주·제천·단양.
- 2026-07-01 개편(인천 제물포구·영종구·서해구·검단구, 화성시 4개 일반구)이 반영되어 있다.

### 연도별 정원 자료를 찾은 경로

보건복지부 보도자료와 공고 게시판에는 병원별 표가 없었고, 언론 보도도 일부 병원만 인용하고 있었다.
전공의 모집 공고문에 적힌 전형시스템 주소(`kha.career.co.kr`)를 단서로
**대한병원협회 수련환경평가본부**(`sinim.kha.or.kr`) 공지사항 게시판에 닿았고, 거기에서
「(변경) 2023년도 전공의(인턴 및 레지던트 1년차) 정원 통보 및 정원 탄력운영 관련 안내」
(2022-11-21 등록, 2023-02-01 변경)의 공개 첨부 PDF 두 개를 받았다. 근거는 보건복지부 의료인력정책과-3140.
같은 게시판에 **2024·2025·2026년도 정원**도 공개되어 있어 네 해를 모두 받았다.
표는 `pdfplumber` 로 열 단위로 읽어 기본정원·미충원 별도정원·정책적 별도정원·감원을 각각 보존했다.
머리글이 해마다 달라(2025년부터 '최종정원' 열, 2026년부터 '감원' 열) 열 위치를 고정하지 않고
머리글을 읽어 역할을 찾는다.

공고 본문에 적힌 변경 이력(동강병원 인턴 3→0, 국립정신건강센터 정신건강의학과 정책적 별도정원 1→0,
일산백병원 안과 0→1·전북대병원 안과 2→1)이 반영된 최종본이다. 확정 당시 보도된 총계(인턴 3,258 · 레지던트 3,465)와의
차이(인턴 3명·레지던트 1명)가 이 변경 이력과 정확히 맞는다. 두 수치를 모두 「데이터 정보」 창에 싣고 어느 쪽이 무엇인지 적었다.

2025년·2026년 표에는 '최종정원' 열이 있어, 집계한 합계가 그 열의 합계(2025년 인턴 3,356·레지던트 3,639,
2026년 인턴 3,275·레지던트 2,827)와 일치하는지 대조했다. 2026년 레지던트 정원이 2025년보다 812명 적은 것은
파싱 누락이 아니라 원문 그대로의 값이다.

> 국군수도병원처럼 기본정원 칸이 비어 있고 별도정원에만 값이 있는 행이 있다. 초기 파서는 이런 행을 버려
> 해당 기관이 2023~2025년 자료에서 빠졌다. 지금은 숫자가 하나라도 있으면 싣고, 기본정원은 0으로 둔다.

### 자동 수집에 관하여

- 행정구역 경계는 CC BY 4.0 공개 저장소에서 내려받았다.
- 주소·좌표·진료과목·병상·인력은 공공데이터포털에 공개된 심평원 파일데이터를 내려받아 썼다. 237개 병원 중 **231곳**이 여기서 채워진다.
- 심평원 명부에 없는 기관만 OpenStreetMap Overpass API 와 Nominatim 으로 보완했다. Nominatim 이용 정책에 따라 식별 가능한 User-Agent 로 초당 1건 이하로 호출했다.
- 기관명이 출처마다 달라(법인격 유무, 괄호 지역 표기, 축약) 이름 327개 중 321개가 심평원 기관과 이어졌다. 그중 46개는 자동 매칭이 틀리거나 비어 `data/curation/hira-overrides.json` 에 사람이 직접 짝지었고, 6개는 요양기관이 아니거나 폐원해 일부러 비워 두었다. 같은 요양기관으로 확인된 레코드 32건은 심평원 ID 기준으로 병합했다(예: 이름을 바꾼 온종합병원→온병원의 2023·2024·2026년 표기 셋).
- 접근 제한을 우회한 수집은 하지 않았다. 로그인이 필요한 경로는 쓰지 않았고(로고 예외는 아래 "로고" 참고), 보건복지부 자료는 보도자료 페이지에 공개된 첨부 파일을 그대로 내려받았다.
- 2023년 모집 자료처럼 공식 원문을 못 구한 항목은 언론 보도를 2차 자료로 쓰되, 출처와 `일부확인` 상태를 함께 적고 화면에도 경고를 띄운다.
- 자동 매칭 결과는 그대로 믿지 않고, 좌표가 해당 기관의 소재 시군구 경계 안에 들어오는지 점-다각형 검사로 확인했다. 틀린 매칭과 비어 있던 항목은 `data/curation/coordinates.json` 에 사람이 확정해 두었다.

### 로고

병원·대학 로고는 각 기관의 **상표**다. 저장소와 배포본에 포함하되, 상표권은 각 기관에 있고 이 프로젝트가 사용 허락을 받은 것은 아니다. 기관 식별 목적으로만 쓰며, 기관을 사칭하거나 후원 관계를 암시하는 데 쓰지 않는다. 기관의 요청이 있으면 해당 로고를 뺀다.

**수록 범위: 한국 304곳, 일본 289곳 — 전 기관(로고 없는 기관 0곳).** 상세 패널 맨 위에 높이 64px 로 크게 보인다.

| 출처 | 방법 |
|---|---|
| 사용자가 모아 둔 로고 폴더 | 파일명 자동 대조 + 이름이 달라 사람이 짝지은 것(manifest `manual`) |
| 기관 공식 누리집 | `fetch_logos.py`·`fetch_logos_browser.mjs`·`harvest_logos.mjs` 로 후보를 받고, `logo_sheet.mjs` 후보 시트를 보고 **사람이 한 장씩 눈으로 확인해 고른 것만** 썼다 |
| Internet Archive | 누리집이 해외 접속에 응답하지 않는 和歌山県立医科大学(대학·본원·紀北分院)만, 보존된 원본 로고 파일을 썼다 |

- 누리집에서 받은 로고는 manifest 에 이미지 주소(`sourceUrl`)나 받은 페이지(`pageUrl`)를 남긴다. 페이지 첫 화면에서 잘라 낸 것은 `capture`·`crop` 에 그렇게 적었다.
- 전화번호·표어·안내 상자가 같이 잡힌 곳은 `crop`(잘라 내기)이나 `erase`(그 부분만 지우기)로 정리했고, 모든 래스터 로고는 둘레 빈 여백을 자동으로 잘라 화면에서 작아 보이지 않게 했다.
- 흰 글자 로고는 `background: "dark"` 로 표시해 화면에서 어두운 판 위에 놓는다.
- **자체 로고가 없거나 구할 수 없는 곳은 가장 가까운 공식 로고를 쓰고 manifest `note` 에 사유를 적었다**: 보건대학원 2곳·국립암센터연구소(소속 기관), 국립법무병원(법무부), 산업안전보건연구원(한국산업안전보건공단), 상주적십자병원(대한적십자사), 건양대학교부여병원(옛 도메인 만료, 건양대학교병원), 전북대학교치과병원(전북대학교병원 누리집 안), 동의병원(동의의료원). 일본 대학병원 30곳은 소속 대학 로고(`university-fallback`).
- 치과대학·歯学部는 같은 대학 의과대학이 있으면 그 대학 로고를 함께 쓴다(manifest `same-logo:`).
- **robots.txt** — 처음에는 robots.txt 가 막은 누리집을 건너뛰었으나, 사용자 판단에 따라 로고 한 장을 받으려고 첫 화면을 한 번 여는 것은 크롤링이 아니므로 막힌 곳도 열었다(기관마다 한 번, 첫 화면만).
- **비트맵 로고 목록** — SVG 가 아닌 PNG·JPG·GIF 로고는 `LOGOS_BITMAP.md` 에 기관·크기·원본 주소와 함께 모아 두었다. 벡터 원본을 구하면 바꿔 넣을 대상이다(`python scripts/list_bitmap_logos.py` 로 다시 만든다).

```bash
python scripts/build_logos.py          # 매핑 manifest 만 미리 만든다
python scripts/build_logos.py --copy   # public/logos/ 로 사본을 복사한다
python scripts/list_bitmap_logos.py    # 비트맵 로고 목록 LOGOS_BITMAP.md
npm run build:data                     # 실제로 복사된 로고만 데이터에 연결한다
```

원본 폴더는 읽기만 하며 덮어쓰지 않는다. 파일명과 기관명이 어긋나면 `data/curation/logo-manifest.json` 의 `fileName` 을 고치고 `manual: true` 로 두면 자동 매칭이 그 항목을 건드리지 않는다. manifest 에는 개인 PC 의 절대 경로를 남기지 않고 폴더 번호와 파일명만 적는다.

### 데이터가 없는 항목 (화면에 "미확인"으로 표시됨)

1. **병원 연혁** — 서술형 연혁은 싣지 않았다(미확인). 심평원 **개설일자**는 확보했다.
2. **운영 센터** — 암센터·심뇌혈관센터처럼 병원이 스스로 이름 붙인 센터 조직은 공식 명부에 없어 수집하지 않았다. 법정 진료과목은 전부 수록했다.
3. **지원자 수 · 합격자 수 · 실제 임용 인원** — 전부 미확인. 정원·모집인원과 혼용하지 않는다.
4. **2023년 하반기 병원별 모집인원** — 전국 총계(인턴 114명 44개 병원, 레지던트 614명 196개 병원)만 언론 보도로 확인했다. 상반기 정원은 공고 원문에서 전량 수록했다.
5. **근사 좌표 8곳** — 좌표 미확인 기관은 없다. 다만 연세대학교보건대학원(입주 건물 미확인, 의과대학 좌표로 대신)과 의과대학 7곳(가천대·가톨릭관동대·건양대·고신대·대구가톨릭대·을지대·차의과학대)은 OSM 에 의과대학 건물이 없어 캠퍼스나 부속병원 지점을 찍었다. 상세 패널에 `approximate` 와 함께 무엇을 찍었는지 적는다.
6. **심평원 명부에 없는 기관 5곳** — 요양기관이 아닌 수련기관 4곳(서울대·연세대 보건대학원, 산업안전보건연구원, 국립암센터연구소. 상세 패널에 "수련기관(비요양기관)"으로 표시)과 문을 닫은 인제대학교서울백병원(2023-08-31 폐원). 경희의료원 교육협력 중앙병원(옛 김해중앙병원)은 지금 운영하지 않아 지도에서 뺐다(아래 "지금 운영하지 않아 뺀 기관"). 좌표는 OSM·Nominatim, 주소는 기관 공식 안내에서 받았다. 정원 자료에는 있으므로 기관으로는 유지하고 사유를 `data/curation/hira-overrides.json` 에 적었다. 나머지 **231곳은 심평원 명부와 이어져** 주소·좌표·종별·진료과목·병상을 공식 값으로 채운다. 상급종합병원으로 지정된 47곳은 전부 심평원 종별도 '상급종합'으로 일치한다(단위 테스트로 검증).
7. **의과대학 소재지와 지도 위치가 다른 곳** — 메디컬 목록 엑셀은 대학 본교 소재지를 적는데, 의과대학 건물은 다른 곳에 있는 경우가 많다(서울대 관악→종로 연건, 연세대(미래) 서대문→원주, 영남대 경산→대구 남구, 인제대 김해→부산진구 등 12곳). 권역 필터는 **지도 위치(교육 장소)**를 따르고, 엑셀 소재지는 상세 패널 좌표 설명에 함께 적는다. 울산대 의대는 2025년부터 울산 동구 아산의학관에서 교육하므로 서울아산병원 부지가 아니라 울산에 찍는다.
8. **병상 구분** — 심평원 시설 신고 기준(일반입원실·중환자실·정신과·격리·무균치료실)으로 세부 내역까지 싣지만, 이것이 허가병상인지 운영병상인지는 원자료에 구분이 없다.

### 지금 운영하지 않아 뺀 기관

- **경희의료원 교육협력 중앙병원**(옛 김해중앙병원) — 2023년 정원 표에는 있으나 2023년 10월 경영난으로 진료를 멈췄다. 2025년 3월 공매로 더복음병원 측이 낙찰받아 재개원을 계획했지만 2026년 7월 기준 잔금을 마련하지 못해 불투명하고, 심평원 2026-09 명부에도 없다(2026-11-10 확인). 기관·관계·모집 기록을 함께 뺐으므로 2023년 인턴 정원 합계가 원문 총계(3,255명)보다 3명 적다.
- 목록과 근거는 `data/curation/excluded-institutions.json`, 빌드 마지막 단계(`build_data.py`)에서 걸러 낸다. 2023-08-31 폐원한 인제대학교서울백병원은 아직 목록에 넣지 않았다.

### 아직 구현하지 않은 기능

- **센터 엔티티** — 타입과 빈 컬렉션만 있다. 진료과목은 전부 채워져 있고, 센터만 비어 있다.
- **2023년 하반기 병원별 모집인원** — 위 4번 참고.

### 구현한 지도 동작 (참고)

- **권역응급의료센터 관할 권역 하이라이트** — 권역응급의료센터를 선택하면 그 센터가 맡은 **공식 관할 응급의료권역**을 붉은 점선으로 칠한다. 필터로 고른 탐색용 권역(초록)과 색을 달리해 섞이지 않게 했다. 기관이 있는 지리적 권역·공식 관할 권역·탐색용 권역 셋을 각각 다른 값으로 저장한다.
- **같은 좌표에 모인 기관** — 연세대학교 의과대학과 보건대학원처럼 같은 지점을 쓰는 기관이 한 점에 겹친다. 지도에서는 작은 원 위로 흩어 놓아 각각 누를 수 있게 했다. **표시 전용 보정**이며 데이터의 좌표와 상세 패널에 보이는 값은 그대로다.
- **같은 이름의 다른 기관** — 누네안과병원(서울 강남·대구 중구), 명지병원(고양 덕양·제천)처럼 심평원 명부에 같은 이름이 여러 곳 있는 경우가 있다. 지도와 목록에서는 표시명에 소재 시군구를 덧붙여 구별한다.

### 원자료에서 발견한 오류

메디컬 목록 엑셀의 「관련 병원」 열에서 세 대학의 본원이 빠지고 분원이 두 번 적혀 있었다 (경북대 → 칠곡경북대 2회, 경희대 → 강동경희대 2회, 부산대 → 양산부산대 2회). 원본은 고치지 않고, `data/curation/relation-corrections.json` 에 보완 관계를 근거와 함께 추가했다. 상태는 `일부확인`이다.

보건복지부 「권역응급의료센터 현황」(2023) 붙임 원문에 "한람대학교성심병원"이라는 오기가 있어 "한림대학교성심병원"으로 바로잡아 옮겼고, 그 사실을 `data/designations.json` 에 적었다.

### 기관 식별에서 주의한 점

정원 공고는 기관을 약칭으로 적고, 해마다 표기가 달라진다. 특히 **뒤에 붙은 지역 표시는 서로 다른 기관을 가르는 정보**다.

- `부민병원(서울)`(서울 강서구)과 `부민병원(부산)`(부산 북구)은 다른 병원이다. 2024년 표부터 부산 쪽이 지역 표시 없이 `부민병원` 으로 적히는데, 그대로 두면 서울 쪽과 합쳐진다.
- `누네안과병원` 은 심평원 명부에 서울 강남·경기 남양주·대구 중구 세 곳이 있다.
- `한국원자력의학원 원자력병원`(서울 노원)과 `동남권원자력의학원`(부산 기장)은 다른 기관이다.

그래서 기관 식별 키(`normalize`/`core`)에서는 지역 표시를 떼지 않고, 심평원 명부와 이름을 맞출 때 쓰는 `match_key` 에서만 뗀다. 같은 이름이 여럿일 때는 `hira-overrides.json` 에 `"요양기관명|시도"` 로 지정한다. 검증 스크립트가 **한 기관·한 해·한 과목에 기록이 둘이면 오류**로 잡아 재발을 막는다.

## 배포

GitHub Pages 를 전제로 준비했다. 별도 서버가 필요 없다 — 지도 타일 서버도, API 키도, 백엔드도 쓰지 않는다.

`.github/workflows/deploy.yml` 이 들어 있다. 저장소 설정에서 **Settings → Pages → Source: GitHub Actions** 를 켜면 `main` 에 푸시할 때마다 빌드·배포된다.

수동 배포:

```bash
MEDMAP_BASE=/<저장소이름>/ npm run build
# dist/ 를 정적 호스팅에 올린다
```

### 공개 전 점검

- [x] API 키·토큰 없음 (외부 유료 서비스를 쓰지 않는다)
- [x] 개인 PC 절대 경로가 코드에 없음 (환경변수로 받고 기본값만 스크립트 안에 둔다)
- [x] 사용자 계정 정보 없음
- [x] 대용량·임시 파일 제외 (`.cache/`, `dist/`, `node_modules/`, `test-results/`)
- [x] 경계·좌표 데이터의 라이선스와 출처 표시
- [x] 기관 로고 — 저장소에 포함. 상표권은 각 기관에 있으며 식별 목적으로만 쓴다(위 "로고" 참고).
- [ ] 원자료 PDF·엑셀은 저장소에 넣지 않았다. 재배포 조건을 확인하지 않았기 때문이다.
